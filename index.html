Autorizzazione ricevuta ✅

Questa è la pagina di callback OAuth per l'app AliExpress Affiliates API di OSA. Se vedi questa schermata, il reindirizzamento dall'autorizzazione AliExpress ha funzionato.

  1. Torna all'ambiente OSA sul Mac per completare lo scambio del codice con il token.
  2. Il codice di autorizzazione si trova nella barra degli indirizzi del browser (dopo ?code=) e scade in circa 3 minuti: usalo subito.
Per sicurezza questa pagina è statica e non legge, non mostra e non memorizza il parametro code né alcun altro dato. Nessuna chiave o segreto è contenuto qui.
